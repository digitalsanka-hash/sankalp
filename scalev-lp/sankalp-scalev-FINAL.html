Saya benar-benar awam. Apakah bisa memakai SankaPage?

Bisa. Anda mengedit lewat kolom formulir: ganti teks, pilih warna, unggah gambar, lalu melihat hasilnya langsung di preview.

Apakah ini langganan bulanan?

Tidak. Penawaran pada halaman ini adalah sekali bayar untuk akses selamanya.

Apakah bisa dipakai untuk banyak produk?

Bisa. Buat proyek baru dari template atau duplikat proyek yang sudah ada untuk membuat versi produk lain.

Bagaimana memasangnya ke ScaleV?

Isi link checkout di editor, download file HTML, lalu gunakan fitur Custom HTML atau alur unggah yang tersedia di akun ScaleV Anda.

Apakah gambar ikut masuk ke file HTML?

Ya. Gambar yang diunggah ditanam ke file HTML sehingga tidak perlu hosting gambar terpisah.

Apakah Meta Pixel bisa dipasang?

Bisa. Masukkan Pixel ID pada bagian integrasi sebelum mengunduh HTML.
