SANKALP — LANDING PAGE SCALEV
================================

FILE FINAL:
  sankalp-scalev-FINAL.html

SEBELUM DEPLOY:
1. Buka build.mjs.
2. Ganti CHECKOUT_URL dengan link checkout ScaleV.
3. Opsional: isi WHATSAPP_URL dan META_PIXEL_ID.
4. Jalankan dari folder proyek:
     node scalev-lp/build.mjs
5. Upload/tempel isi sankalp-scalev-FINAL.html ke Custom HTML ScaleV.
6. Uji dari HP dan klik semua tombol checkout sebelum menjalankan iklan.

CATATAN:
- File final mandiri; gambar dan preview template sudah ditanam.
- Jangan mengedit file FINAL untuk perubahan besar. Edit source lalu build ulang.
- Jangan menjalankan iklan sebelum link checkout benar.
